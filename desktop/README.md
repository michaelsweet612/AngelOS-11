# AngelOS 11 Desktop Layer (Latest KDE Plasma 6)

Directory breakdown for Windows 11 visual & behavioral fidelity:

- `plasma-look-and-feel/` — Global AngelOS 11 Light & Dark Plasma 6 Look-and-Feel packages
- `plasmoids/` — Customized Start Menu (`Menu 11 Next`/`Enhanced`), Quick Settings, and Taskbar QML widgets
- `kwin/` — `Klassy`, `kwin-effects-better-blur-dx`, `KDE-Rounded-Corners`, `snap11` presets, and KWin rules
- `kvantum/` — AngelOS Mica Light & Dark Qt6 themes
- `gtk/` — Matching Fluent GTK3 & GTK4 themes
- `oobe/` — First-Boot Light/Dark Mode & accent picker wizard (Qt6/QML)
- `sddm/` — Windows 11 Qt6 SDDM lock & login screen (`win11-sddm-theme` customized)
- `plymouth/` — AngelOS 11 boot splash with spinning ring
- `assets/` — Original AngelOS wing/halo emblem, Bloom Light/Dark wallpapers, Selawik font configs, Fluent SVG icons, cursors, ambient sounds
- `skel/` — Default `/etc/skel` configs (Dolphin Explorer layout, Windows 11 shortcuts, Plasma panel layout)
