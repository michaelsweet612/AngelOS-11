# AngelOS 11 Packages & PKGBUILDs

Custom Arch Linux `PKGBUILD` recipes live here, including:

- `angelos-desktop-meta` — Meta-package pulling latest KDE Plasma 6, Klassy, Kvantum, Dolphin, Edge, Discover, Flatpak, and core KDE apps
- `angelos-win11-shell` — AngelOS taskbar layout, Start Menu (`Menu 11 Next`/`Enhanced`), Quick Settings, and Look-and-Feel packages
- `angelos-kwin-plugins` — Reproducible builds of `kwin-effects-better-blur-dx`, `KDE-Rounded-Corners`, and `snap11` rebuilt automatically against the latest Arch Plasma 6 ABI
- `angelos-wine-compat` — Wine Staging + DXVK + VKD3D + `angelos-wine-runner`
- `angelos-calamares-config` — Calamares branding, modules, and Btrfs + Snapper + GRUB layout
